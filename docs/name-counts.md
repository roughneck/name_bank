# Names available per country

Pool sizes in the committed data. Each country provides up to 1500 given
names per gender and up to 1500 surnames; the actual count is smaller where
the source data has fewer. 35 countries additionally provide a native-script
pool (`script: :native`); a dash means that country has no native pool.
`China` and `Ukraine` are small hand-curated (romanized) pools.
